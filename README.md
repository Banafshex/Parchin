# پرچین (Parchin)

برنامه‌ی ساده، سبک و متن‌باز اندروید برای مسدود کردن تماس‌های ورودی با پیش‌شماره‌های دلخواه، مثل `+98942` یا `+98990`.

## امکانات
- ورود پیش‌شماره‌ی ۳ تا ۶ رقمی بعد از `+98` ثابت (صفر ابتدایی خودکار حذف می‌شود)
- رد کامل تماس‌های ورودی که با پیش‌شماره‌های لیست شروع شوند
- ادامه‌ی کار حتی وقتی برنامه کاملاً بسته است (سیستم اندروید خودش سرویس را اجرا می‌کند)
- تنظیمات اختیاری: خاموش/روشن کلی، استثنا برای مخاطبین ذخیره‌شده، ثبت یا عدم ثبت در تاریخچه‌ی تماس‌ها، اعلان تماس مسدودشده
- رابط کاملاً فارسی و راست‌چین با فونت وزیرمتن، حجم کم و بدون هیچ کتابخانه‌ی اضافه

## نحوه‌ی استفاده
۱. برنامه را نصب و باز کنید.
۲. دکمه‌ی «فعال‌سازی مسدودسازی تماس» را بزنید و پرچین را به‌عنوان برنامه‌ی غربالگری تماس انتخاب کنید.
۳. پیش‌شماره‌ها را اضافه کنید.

## محدودیت‌ها
- فقط تماس‌های **ورودی** مسدود می‌شوند؛ اندروید اجازه‌ی مسدود کردن تماس خروجی را به برنامه‌های عادی نمی‌دهد.
- حداقل اندروید ۱۰ (API 29) لازم است.
- هیچ داده‌ای از دستگاه خارج نمی‌شود و برنامه مجوز اینترنت ندارد.

## ساخت از سورس
```bash
bash tools/get-fonts.sh        # دانلود فونت وزیرمتن
gradle wrapper                 # فقط بار اول (اختیاری)
./gradlew assembleRelease
```
فایل APK در مسیر `app/build/outputs/apk/release/` ساخته می‌شود. با هر push روی GitHub هم Actions خودکار APK می‌سازد (بخش Artifacts).

## مجوز
کد برنامه تحت مجوز MIT است. فونت وزیرمتن تحت مجوز SIL OFL منتشر شده است.
